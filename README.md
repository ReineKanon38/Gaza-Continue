# SISTEMA-GAZA

Aplicacion ecommerce con frontend en React/Vite y backend en Node/Express.

## Estructura

- frontend: aplicacion web
- backend: API y logica de negocio
- docs: documentacion operativa e historica

## Requisitos

- Node.js 20+
- npm 10+
- MongoDB accesible para backend

## Inicio rapido

1. Instalar dependencias:
	- En frontend: npm install
	- En backend: npm install
2. Configurar variables de entorno:
	- Copiar backend/.env.example a backend/.env
	- Copiar frontend/.env.example a frontend/.env
3. Ejecutar en desarrollo:
	- En backend: npm run dev
	- En frontend: npm run dev

## Seguridad durante desarrollo

- No subir archivos .env ni credenciales reales al repositorio.
- Mantener claves en variables de entorno locales.
- Evitar documentar passwords o tokens reales en archivos markdown.

## Uso en otro repositorio

- Revisar y conservar licencia y avisos legales.
- Mantener atribucion/origen cuando aplique.
- Verificar licencias de dependencias antes de redistribuir.
- Sanitizar datos sensibles antes de publicar.
